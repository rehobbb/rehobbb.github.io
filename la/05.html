方阵的等价说法；谱定理

笔记 §6–§7

可逆组（每条互相等价）：\(A\) 可逆 \(\iff\det A\ne0\) \(\iff\operatorname{rank}A=n\) \(\iff\mathcal N(A)=\{\boldsymbol 0\}\) \(\iff\) 列线性无关 \(\iff\) 列构成 \(\mathbb R^n\) 的基 \(\iff A\boldsymbol x=\boldsymbol b\) 对每个 \(\boldsymbol b\) 有唯一解 \(\iff\) 所有特征值 \(\ne0\)。

奇异组（全部取反）：\(A\) 奇异 \(\iff\det A=0\) \(\iff\operatorname{rank}A<n\) \(\iff\mathcal N(A)\ne\{\boldsymbol 0\}\) \(\iff\) 列线性相关 \(\iff A\boldsymbol x=\boldsymbol 0\) 有非零解 \(\iff\) 有特征值 \(=0\)。

结构翻译（\(K\) 对称）：\(K\) 奇异 \(\iff\) 存在零刚度模式 \(\iff\) 存在 \(\omega=0\) 的模态 \(\iff\boldsymbol u^TK\boldsymbol u=0\) 有非零解（\(K\) 半正定时）。02 篇第 6 节可以改矩阵看八条同时成立或不成立。

对广义问题 \(K\boldsymbol\phi=\lambda M\boldsymbol\phi\)（\(K\) 对称、\(M\) 对称正定），四条通过 Cholesky 桥全部继承，“正交”换成“\(M\)-正交”。

Python 代码卡

笔记 §14–§16

对应源文件 01-Athena/线性代数笔记维护/核对算例.py。依赖 NumPy、SciPy，一致单位，矩阵行列对应同一组自由度。

import numpy as np
from scipy.linalg import eigh


def modal_check(K, M, rtol=1e-10):
    """广义对称特征问题 K φ = λ M φ 的求解与核对。
    要求 K 对称、M 对称正定。负特征值不截断，单独标记。"""
    K, M = np.asarray(K, dtype=float), np.asarray(M, dtype=float)
    if K.ndim != 2 or K.shape[0] == 0 or K.shape[0] != K.shape[1] or M.shape != K.shape:
        raise ValueError("K、M 必须是同尺寸非空方阵")
    if not (np.isfinite(K).all() and np.isfinite(M).all()):
        raise ValueError("矩阵必须全部为有限实数")
    if not np.isfinite(rtol) or not 0 < rtol < 1:
        raise ValueError("rtol 必须位于 0 与 1 之间")
    for name, A in [("K", K), ("M", M)]:
        scale = np.linalg.norm(A, ord="fro")
        if np.linalg.norm(A - A.T, ord="fro") > rtol * scale:
            raise ValueError(f"{name} 不对称")
    # M 非正定时 eigh 会明确报错；不擅自调整输入。
    lam, Phi = eigh(K, M)
    tol = rtol * np.max(np.abs(lam))
    negative = lam < -tol                       # 明显负值：失稳信号
    near_zero = np.abs(lam) <= tol              # 数值近零：零刚度模式
    omega = np.full(lam.shape, np.nan)
    omega[near_zero] = 0.0
    positive = lam > tol
    omega[positive] = np.sqrt(lam[positive])    # 负值保持 nan，不掩盖
    residual = K @ Phi - (M @ Phi) * lam
    denominator = (np.linalg.norm(K, 2) + np.abs(lam) * np.linalg.norm(M, 2)) * np.linalg.norm(Phi, axis=0)
    numerator = np.linalg.norm(residual, axis=0)
    # K=0 且 λ=0 时残差和分母同时为零，定义该精确残差为 0。
    relative = np.divide(numerator, denominator, out=np.zeros_like(numerator), where=denominator > 0)
    return {"lambda": lam, "omega": omega, "frequency_hz": omega / (2 * np.pi),
            "negative": negative, "near_zero": near_zero,
            "relative_residual": relative,
            "mass_gram": Phi.T @ M @ Phi,        # 应 ≈ I
            "stiffness_gram": Phi.T @ K @ Phi,   # 应 ≈ diag(λ)
            "Phi": Phi}


M = np.diag([2.0, 1.0])
K = np.array([[3.0, -1.0], [-1.0, 1.0]])
result = modal_check(K, M)
for key, value in result.items():
    print(key, "\n", value)

主算例应得到 \(\lambda=[0.5,\ 2]\)、\(f\approx[0.112540,\ 0.225079]\) Hz，质量 Gram 矩阵约为单位阵，刚度 Gram 矩阵约为 \(\mathrm{diag}(0.5,2)\)，残差在 \(10^{-16}\) 量级。

def rayleigh(K, M, x):
    x = np.asarray(x, dtype=float)
    return (x @ K @ x) / (x @ M @ x)

# 所有 R 都应 >= λ1 = 0.5；输出 0.5, 0.5038, 0.6667, 1.5
for x in ([1, 2], [1, 1.8], [1, 1], [1, 0]):
    R = rayleigh(K, M, x)
    print(f"x={x}: R={R:.6f}, ω上界={np.sqrt(R):.4f}")

# 半正定 K：单弹簧连两个自由质点 → 一个零频
modal_check(np.array([[1., -1.], [-1., 1.]]), np.eye(2))["near_zero"]   # [True, False]
# 不定 K：出现负特征值，omega 为 nan
modal_check(np.array([[1., 2.], [2., 1.]]), np.eye(2))["negative"]      # [True, False]
# 重根：M=K=I，任何基都是特征向量，Gram 仍为 I
modal_check(np.eye(2), np.eye(2))["mass_gram"]
