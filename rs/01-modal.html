从振型到地震力：一个三层框架算到底

用一个 3 层剪切型框架，从运动方程出发，依次推出周期与振型、参与系数、有效质量、各振型地震作用和振型组合，再用时程分析检验，最后对照底部剪力法和盈建科输出。页面数值全部实时计算，可修改参数观察变化。

①

算例：三层剪切型框架

楼板无限刚、柱子只提供层间抗侧刚度，每层只有一个水平自由度。层重力荷载代表值 Gi，层侧向刚度 ki，层高 4 m。地震参数取 7 度（0.10g）多遇地震，II 类场地，设计地震分组第一组，阻尼比 5%。

目标：求地震作用下各层的地震力、层剪力和层间位移。

已修改参数，第 ⑨ 节仍为默认算例

记号约定。下标 j 表示振型号，i 表示楼层号（1 为首层）。粗体为向量或矩阵，斜体为标量。Σ 不加说明时，指固定振型 j、对楼层 i = 1～3 求和；对振型求和写作 Σj。

②

运动方程：地震对结构做了什么

质量矩阵

质量集中在楼板处，第 i 层质量 mi = Gi/g（单位 t）。三层质量排成对角矩阵，非对角元为 0：

M = diag(m1, m2, m3) = diag() t

M 是矩阵，mi 是它的第 i 个对角元（标量）。后文凡出现 Σmi(…)，都是矩阵乘积在对角质量阵下的展开。

刚度矩阵

刚度矩阵不是把层刚度直接填进去，而是由层刚度组装而成。K 的第 j 列，等于“只让第 j 层平移 1 m、其余层固定”时各层需要施加的力。例如首层平移 1 m，首层柱和二层柱都被错动 1 m，所以首层要施加 k1+k2，二层要施加 −k2 把它拉住；顶层上面没有楼层，所以 K33 只有 k3。

K = k1+k2−k20−k2k2+k3−k30−k3k3 = kN/m行、列顺序：首层、二层、顶层

地面运动的输入

记各层相对地面的位移为 u = {u1, u2, u3}T。地面平移 ug 时，各层的绝对位移可以拆成两部分：随地面整体平移的 {1}ug，加上相对变形 u。这里 {1} = {1, 1, 1}T 叫影响向量，表示地面移动 1 个单位时各层被刚性带动的位移。这只是对运动的拆分，并不假设结构刚性，结构的柔性全部体现在 u 里。

惯性力取决于绝对加速度 ü + {1}ag，由牛顿定律 M(ü + {1}ag) + K u = 0，把已知的地面项移到右边：

M ü + K u = −M{1}ag阻尼项后面以振型阻尼比 ζ 计入

这一步是精确的。右边就是地震对结构的等效荷载：第 i 层为 −miag，与该层质量成正比。注意各层的真实加速度是 ag + üi，并不等于 ag；“全是 1”的是荷载分布中的影响向量，不是真实加速度。

困难在于 K 不是对角阵：首层方程里含有二层位移，三个方程互相耦合，不能逐个求解。要把它拆开，需要先找到结构自己的振动形态，也就是振型。
③

周期与振型：结构自己会怎么振

先看没有地震、结构自由振动的情形：M ü + K u = 0。寻找一种“保持形状、同步振动”的运动：

u(t) = X·sin(ωt)X 是 3×1 向量（各层振幅，即振型）；sin(ωt) 是三层共用的标量时间函数

它的含义是三层按同一频率、同一相位振动，各层位移之比始终是 X1 : X2 : X3。代入方程，ü = −ω²X sin(ωt)，消去标量 sin(ωt) 得

(K − ω²M) X = 0  ⇔  K X = λM X，  λ = ω²

这是广义特征值问题。它和熟悉的标准形式 (A − λI)X = 0 的区别只是右边多了 M：左乘 M−1 即得 A = M−1K，特征值和特征向量都不变。标准形式隐含“各自由度质量都为 1”；各层质量相等时 M = mI，问题就退化为 (K/m − λI)X = 0。程序一般改用对称形式 M−1/2K M−1/2，以保留 K、M 对称带来的性质。

要有非零解 X，必须 det(K − λM) = 0。3 个自由度得到一个关于 λ 的三次方程，3 个根对应 3 个圆频率 ωj 和周期 Tj = 2π/ωj；每个根代回方程，得到对应的振型 Xj。

振型的大小需要约定：归一化

(K − λM)X = 0 只能确定 X 的形状，X 乘任意常数仍是解。使用前必须约定一把“尺子”，常用两种：

  • 顶层 = 1：直观，适合画图和手算。TMD/TLD 设计也采用这类约定，取阻尼器安装位置的振型值为 1。
  • 质量归一：缩放到 XjTM Xj = ΣmiXji² = 1。维度为 (1×3)(3×3)(3×1)，右边的 1 是标量。有限元软件的特征值求解一般直接输出这种形式，后面会看到它让公式最简。

振型的关键性质：正交

不同振型关于 M 和 K 都正交，j ≠ k 时 XkTM Xj = 0、XkTK Xj = 0。这是特征值问题自带的性质，不是人为规定。本例核验：。把三个振型排成矩阵 Φ = [X1 X2 X3]，则 ΦTMΦ 和 ΦTKΦ 都是对角阵；质量归一时 ΦTMΦ = I，ΦTKΦ = diag(ω1², ω2², ω3²)。正交性正是下一步解耦的钥匙。

④

解耦：模态质量与振型参与系数

回到地震下的方程 M ü + K u = −M{1}ag。3 个振型线性无关，任何位移都能写成它们的组合，于是换一套坐标：

u(t) = Σj Xj qj(t)qj(t) 为振型坐标，是标量时间函数

代入方程并左乘 XjT，由正交性，所有交叉项为零，只剩第 j 个振型自己：

(XjTM Xj) q̈j + (XjTK Xj) qj = −(XjTM{1}) ag

三个括号各有名字：

  • 模态质量（广义质量）M*j = XjTM Xj = ΣmiXji²，是等效单自由度体系的质量；
  • 模态刚度 K*j = XjTK Xj = ωj²M*j；
  • 激励项 Lj = XjTM{1} = ΣmiXji，是地震荷载在第 j 振型上的投影。

两边除以 M*j，并按振型阻尼比 ζ 计入阻尼，三个耦合方程变成三个独立的单自由度方程：

q̈j + 2ζωjq̇j + ωj²qj = −γjag
γj = LjM*j = ΣmiXjiΣmiXji² = ΣXjiGiΣXji²Gi振型参与系数；抗规 5.2.2-2、高规 4.3.9（g 上下约掉）

振型参与系数 γj 就是在解耦时自然出现的：它是地震荷载投影到第 j 振型、再除以模态质量后的系数。质量归一时 M*j = 1，γj 简化为 ΣmiXji。

解出来是什么：γX 的含义

记 Dj(t) 为周期 Tj、阻尼比 ζ 的单自由度振子在同一条 ag(t) 下的位移反应。它满足的是不带 γ 的标准方程，反应谱就是用这个方程定义的：

D̈j + 2ζωjḊj + ωj²Dj = −ag单位激励的标准振子

两边同乘常数 γj（γ 不随时间变，可以移进导数里）：

(γjDj)·· + 2ζωj(γjDj)· + ωj²(γjDj) = −γjag

这和上面的振型方程一字不差。两者都从静止开始（初位移、初速度为 0），同一个方程、同一组初始条件只有一个解，所以 qj = γjDj(t)。本质是线性：输入放大 γj 倍，反应也放大 γj 倍；γj 为负时反应整体反号。代回坐标变换：

u(t) = Σj (γjXj) · Dj(t)

所以 γjXj 是“单自由度振子位移为 1 时，第 j 振型引起的各层位移”。多自由度结构的反应，就是 3 个单自由度振子的反应各乘一个固定形状后叠加。

回头看：γ 把地面运动“分配”给各振型

3 个振型可以作为 3 维空间的一组基，影响向量 {1} 一定能写成 {1} = c1X1 + c2X2 + c3X3，cj 为标量系数（类比 v = 3i + 4j）。两边左乘 XkTM，由正交性得 ck = Lk/M*k，正好就是 γk：

{1} = Σj γjXj，  每层 Σj γjXji = 1

通俗地说：地震把每层都往同一边推（按质量分配力），而这栋楼只会三种固有“姿势”，推力只能拆成三种姿势的组合。右图就是拆分结果，每层三段之和为 1：绝大部分分给了姿势 1，姿势 2、3 只分到一点。

γ 本身的数值没有意义，γX 才有

振型乘以常数 c 时，Lj 变为 c 倍，M*j 变为 c² 倍，γj 变为 1/c 倍，而乘积 γjXj 不变。好比“长度 = 数字 × 单位”：X 是单位，γ 是数字，3 米 = 300 厘米，数字随单位变，长度不变。切换上面的归一化按钮可以看到：下表的 γ 和 X 都在变，γX 列不变。所以比较振型的重要性，不能看 γ 的大小，要看下一节与缩放无关的有效质量。

同样，模态质量 M*j 也随缩放变化，只有约定了归一化方式才是确定值。例如 TMD 设计约定阻尼器所在位置振型值为 1，阻尼器装在顶层时，本例 M*1 = t，这就是质量比 μ = mT/M*1 的分母；质量归一时则 M*1 = 1。

γ 与 X 分开存放还有一个原因：X 只属于结构，γ 还取决于地震方向。空间模型中，x 向地震的影响向量只在 x 自由度取 1，得到 γxj；y 向同理得到 γyj。任意方向 θ 时 γtj = γxjcosθ + γyjsinθ（抗规 5.2.3）。一套振型可以配多个方向的 γ。

⑤

有效质量：振型取多少才够

把 γ 和 L 组合成一个与缩放无关的量，即有效质量：

Meff,j = Lj²M*j = γjLj，  Geff,j = Meff,jg = (ΣXjiGi)²ΣXji²Gi，  有效质量系数 = Geff,j/ΣGi

全部振型加起来恰好是总质量

对 {1} = ΣjγjXj 两边左乘 {1}TM：左边 {1}TM{1} = Σmi 为总质量；右边由正交性只剩 Σjγj²M*j = ΣjMeff,j。所以全部振型的有效质量之和恒等于总质量，这是数学恒等式。本例 。

有效质量决定该振型的基底剪力

后面会推出第 j 振型的层地震力 Fji = αjγjXjiGi，沿高度相加得基底剪力：

V0j = ΣFji = αjγjΣXjiGi = αj · Geff,j

它和单质点体系 V = α·G 形式相同。也就是说，只看基底剪力时，第 j 振型相当于一个周期为 Tj、重量为 Geff,j 的单质点；结构本身仍是 3 个质点，各层的力、上部楼层剪力和层间位移仍要逐层计算。

注意区分两个“质量”：模态质量 M*j 随缩放而变，有效质量 Meff,j 不变。本例振型 1 在顶层 = 1 时 M*1 = t，而 Meff,1 = t，两者不能混用，也不能用“有效质量系数 × 总质量”代替模态质量。

90% 判据从哪里来

实际模型自由度成千上万，只取前 n 阶振型。没取到的振型，其有效质量对应的那部分荷载就没进入计算，这就是截断误差。抗规 5.2.2 条文说明取“振型参与质量达到总质量 90% 所需的振型数”，高规 5.1.13 对 B 级高度和复杂高层明确要求不小于 90%。没有规范要求必须达到 100%；美国 ASCE 7-16 第 12.9.1.1 条要求 100%，同时允许以 90% 作为替代。

90% 通常够用，是因为被截掉的多是短周期的高阶振型，剩余有效质量小，又经平方和开方组合，对基底剪力影响不大。但它只保证底部总量的误差小，不保证每个局部量都准确，后面会看到只取 1 阶时顶层剪力误差远大于基底剪力误差。

⑥

反应谱：每个振子的最大加速度

第 ④ 节把问题化成了 3 个单自由度振子。反应谱给出的正是单自由度振子的最大反应：周期为 T 的振子，最大绝对加速度为 α(T)·g，最大位移 Sd = αg/ω²。规范谱见抗规 5.1.5（阻尼比 0.05：γ = 0.9，η₁ = 0.02，η₂ = 1.0），每个振型按自身周期各取一次 α。

⑦

各振型的地震作用、层剪力、层间位移

第 j 振型的最大位移为 uj,max = γjXjSd(Tj)。对应的弹性恢复力 Fj = K uj,max，利用 K Xj = ωj²M Xj 和 ω²Sd = α g，再以 mig = Gi 代入，得到规范公式：

Fji = αj γj Xji Gi抗规 5.2.2-1；高规 4.3.9    Vji = Σk≥i Fjk    Δji = Vji / ki

三个因子各司其职：X 决定力沿高度的分布形状，γ 与 X 一起决定该振型分到多少地震荷载，α 决定该周期对应的加速度放大。

第 j 振型的各层位移是 Xj·qj(t)，三层共用同一个时间函数 qj(t)，所以同一振型内各层的力在同一瞬间达到峰值，方向由 Xji 的正负决定。每个振型的 Fj1、Fj2、Fj3 因而是同一时刻真实存在的一组力，可以作为一个荷载工况做静力分析，算出的内力相互协调、满足平衡。
⑧

振型组合：为什么不能直接相加

三个振型的输入是同一条 ag(t)，但反应 q1、q2、q3 并不相同。每个振子的反应是一个卷积（Duhamel 积分）：

Dj(t) ∝ ∫ ag(τ) e−ζωj(t−τ) sin[ωj(t−τ)] dτ

每个振子相当于一个“过滤器”，主要放大与自身频率接近的成分，并记住过去一段时间的输入。地震波是宽频随机信号，不同频率成分在时间上分布不均，于是各振子在不同时刻达到峰值。即使输入只是一个瞬时脉冲，各振子也约在 Tj/4 时第一次达峰（本例为 s），之后按各自频率振荡，相位很快错开。振型内部同步，振型之间不同步：前者保证单振型可以做静力分析，后者决定了振型之间只能做统计组合。

SRSS：S = √( Σj Sj² )抗规 5.2.2-3，相邻周期比 < 0.85 时可用
CQC：S = √( Σj Σk ρjk Sj Sk )，  ρjk = 8 ζ² (1+λT) λT1.5(1−λT²)² + 4ζ²λT(1+λT)²抗规 5.2.3（ζj=ζk=ζ 的化简式），λT=Tk/Tj

SRSS 假定各振型峰值互不相关。两个振型周期接近时，两个振子对同一段地震波反应相似，峰值几乎同时出现，SRSS 会低估；CQC 用相关系数 ρjk 把这种相关性补回来。

SRSS 是随机振动理论下的期望值估计，单条波实际峰值可能偏高也可能偏低：40 条波的比值平均 1.008、标准差 5.5%、范围 0.91～1.15，演示的这条波处在正常离散范围内。“峰值绝对值相加”相当于假设所有振型同时达峰，40 条波平均高估约 26%。反应谱法给出的是平均意义上的结果，单条波的离散性也正是规范要求时程补充计算取多条波平均或包络的原因。

⑩

与底部剪力法对照

底部剪力法（抗规 5.2.1）把整栋楼当作一个以第一振型为主的等效单质点：FEk = α1Geq，多质点体系取 Geq = 0.85ΣG。对照第 ⑤ 节，0.85 正是第一振型有效质量系数的经验近似：均匀剪切型结构理论值为 8/π² ≈ 0.81，本例为 。

底部剪力法并不比振型分解法保守，原因有二：

  • α1 是所有振型中最小的 α。第一周期最长，落在反应谱下降段；高阶振型周期短，落在平台段，α 是 α1 的 2 倍以上。底部剪力法把全部重量都按 α1 计算，相当于压低了高阶振型的放大。
  • 0.85 可能低于第一振型的实际有效质量系数，本例即如此。

反过来，当 T1 ≤ Tg、各振型 α 相同时，若第一振型有效质量系数低于 0.85，底部剪力法又会略偏大。所以它只是经过标定的近似，不是保守上限。顶部附加地震作用 ΔFn = δnFEk（T1 > 1.4Tg 时）用来近似高阶振型的鞭梢效应，它从 FEk 中分出，不增加基底剪力。底部剪力法不做振型截断，90% 判据对它不适用；其适用范围限于抗规 5.1.2 规定的高度不超过 40 m、以剪切变形为主、质量和刚度沿高度分布比较均匀的结构。弯曲型结构第一振型有效质量约 61%，用 0.85 偏差会很大。
